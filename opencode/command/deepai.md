DeepAI Code の CLI (`deepai-pi`) を 1 回だけ実行し、その結果を報告してください。

手順:

1. 依頼内容をシェル引用符でエスケープして、次を実行する。
   `deepai-pi --print -- "<依頼内容>"`
2. コマンドの出力を、要約・言い換えをせずそのまま報告する。
3. コマンドが失敗した場合は、エラー出力をそのまま報告して終了する。自分で言い直して実行し直さない。

依頼内容:

$ARGUMENTS
